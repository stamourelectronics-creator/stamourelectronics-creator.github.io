✦   ISAIAHAI INSTALLATION

Install IsaiahAI in Chrome

Follow these three steps on Windows. Each panel contains a diagram and written instructions. You only need to install it once per Chrome profile.

Step 1 · Extract

Unzip the download

  1. Find isaiahai-chrome-extension.zip in Downloads.
  2. Right-click it and choose Extract All….
  3. Keep the extracted folder somewhere easy to find.

Do not choose the ZIP file itself in Step 3.

Step 2 · Chrome

Open Extensions

  1. Open Google Chrome.
  2. Type chrome://extensions into the address bar and press Enter.
  3. Turn Developer mode on in the upper-right corner.
  4. Click Load unpacked.
Step 3 · Load & pin

Choose the extracted folder

  1. Select the folder containing manifest.json, popup.html and service_worker.js.
  2. Click Select Folder or Select.
  3. Click Chrome’s puzzle-piece Extensions menu, then pin IsaiahAI.
  4. Open a normal website and click IsaiahAI to ask questions.

Chrome settings pages and the Chrome Web Store block extensions from reading page content.

To update: open chrome://extensions, remove the old IsaiahAI extension, then repeat with the newest ZIP. These are illustration diagrams; Chrome button placement can vary by version.
