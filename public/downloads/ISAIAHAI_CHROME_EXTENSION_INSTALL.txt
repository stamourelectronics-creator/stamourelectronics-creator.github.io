ISAIAHAI PAGE ASSISTANT — VERSION 1.3.0

WHAT'S INCLUDED
- Toolbar popup chat and a webpage assistant.
- Reads the active tab's readable text and links when you ask a question.
- Captures the visible page screenshot when supported, for questions about diagrams, worksheets, and error dialogs.
- Tries the newer /api/site-assist route and can fall back to the older /api/chat route.
- No OpenRouter API key is stored in the extension. Keep the key server-side in Netlify environment variables.

INSTALL
1. Download and extract isaiahai-chrome-extension.zip.
2. Open chrome://extensions in Chrome and enable Developer mode.
3. Click Load unpacked and choose the folder containing manifest.json and popup.html.
4. Pin IsaiahAI Page Assistant and click its icon to start chatting.

API TROUBLESHOOTING
- Use Test connection in the popup.
- If needed, open extension Settings and enter the exact HTTPS base URL for the deployed IsaiahAI site.
- The extension supports /api/site-assist and older /api/chat; at least one must be implemented.
- Set OPENROUTER_API_KEY (or the legacy ISAIAH_OPENROUTER_API_KEY) in the server's Netlify environment variables and redeploy.
- Never put API keys in extension files or browser-visible assets.

LIMITS
Chrome internal pages and the Chrome Web Store block extension access. Screenshot capture happens only when you press Send.
