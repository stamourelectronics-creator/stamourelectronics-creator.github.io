Your browser. Your space. Meet IsaiahSearch.

A full-window Windows browser with native Chromium tabs, a Firefox-inspired new-tab page, bookmarks, quick-site widgets, recent pages, and IsaiahSearch Agent built directly into the browser. Browse normally, then open the AI drawer to inspect the page, research, attach files, or work through a multi-step task.

Native Chromium tabs, address and navigation controls, bookmark toolbar, top-site shortcuts, recent sites, and a clean full-window workspace without a permanent app header.

IsaiahSearch Agent built in

Open the AI drawer from the browser toolbar. The agent can inspect the current page, open sites in new tabs, and work with the browser instead of acting like a separate assistant app.

Files and multi-step tasks

Attach images, PDFs and text/code files. The agent receives real command output and exit codes, explains errors, can retry approved fixes, and verifies results.

Install and start

1. Download the Windows buildUse the installer for Start Menu/Desktop shortcuts or choose the portable EXE.
2. Launch IsaiahSearchThe browser opens directly to its new-tab page. The operating system may ask you to confirm the app's protocol handler the first time a website opens IsaiahSearch.
3. Open the built-in AI agentClick the AI button in the browser toolbar or press Ctrl+Shift+A. Agent mode is enabled by default.
4. Approve system actionsFile changes and system commands retain Windows approval prompts, workspace boundaries, backups, and UAC protections. Unrestricted system mode requires explicit opt-in after reviewing the warning.
Important system-access warning. When unrestricted system mode is explicitly enabled, AI-generated shell commands can affect files or settings outside the browser. Review the warning carefully, only approve commands and workspaces you trust, and switch unrestricted mode off whenever it is not needed. Windows UAC and app confirmation safeguards remain in place.
