Install and start

1. Download the Windows buildChoose the installer for shortcuts or the portable EXE if you prefer not to install.
2. Approve Windows UACThe application requests Administrator privileges when it starts. Windows displays its normal consent prompt.
3. Choose your AI modelSelect IsaiahAI 7.0 SUPER (OpenRouter) or Breakaway 1.0 (Gemini) in the chat composer.
4. Review the first-run system-mode warningWhen the app first launches, accept the one-time Windows warning to start with unrestricted system mode enabled. AI shell commands then run without separate per-command approval dialogs. Turn it off in Computer tools whenever you like.
Important system-access warning. In unrestricted mode, the AI can issue commands with Administrator permissions. Commands may read, modify, or delete files across the computer, install or remove software, edit the registry, change services, or alter Windows settings. Malicious webpages or files may try to manipulate the AI through prompt injection. Use this only on a computer you control and only when you accept those risks. Windows UAC is not bypassed; you must approve the operating-system prompt at launch. Disabling unrestricted mode restores the per-command review process. AI file-editor writes continue to use a separate Windows confirmation.
