Windows · Chromium · Permissioned computer agent

Bring IsaiahAI onto your computer.

A native Windows companion with a real Chromium-based browser, IsaiahAI chat, and a local workspace for inspecting and editing the folder you choose. Before saving a file or running a command, it asks for approval in a Windows dialog.

↓ Download latest Windows buildBuilds & diagnostics ↗Open web IsaiahAI ↗

The latest release will contain the installer and portable EXE after the first successful Windows build. Windows may show SmartScreen because the app is not code-signed.

🌐

Full Chromium browser

Real website rendering instead of relying on an iframe, persistent site cookies, browser navigation, and an option to open a page in your normal external browser when needed.

🧠

Resilient AI chat

Uses the hosted IsaiahAI backend first and can use a signed-in Puter session as a fallback when available. It does not claim provider limits have been removed.

🗂️

Local project workspace

Select a folder, inspect text/code files, prepare edits, and run development commands. File writes create backups, and all writes and commands need explicit approval.

Install and start

1. Open the latest releaseClick the download button above. Release assets require access to the private source repository.
2. Download the installer or portable EXEChoose the installer for shortcuts or the portable build if you prefer not to install.
3. Launch IsaiahAI AgentWindows may display an unsigned-app warning. Verify that the file came from the IsaiahAI repository.
4. Choose a workspace folderSelect the project folder you want IsaiahAI to inspect. It does not silently scan the entire computer.
Usage and privacy. There is no supported way to guarantee unlimited model usage by bypassing provider quotas. IsaiahAI can use different authorized routes, including your signed-in Puter session, but each provider's usage policy still applies. Local file changes and command execution remain visible and permissioned.
